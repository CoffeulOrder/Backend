## 결과의 범위

검증은 격리된 로컬 DB·테스트 서버에서 수행했다. 원격 개발 DB에는 접속/적용하지 않았고, 서버 설정·실제 PG·Android 화면을 바꾸거나 확인한 결과가 아니다. 신규 Java 운영 코드·Flyway 마이그레이션은 없다. 시드는 개발 보조 registry 테이블을 사용한다.

입력/출력은 합성 QA 정보다. 실제 PG 키, .env, AWS 자격증명, Secrets Manager 값을 열람하지 않았다. 로그·테스트 응답 원문은 전달 묶음에 포함하지 않는다.

11/25 공개 서버 읽기 확인은 health 200/UP, FAKE 확인 경로 노출, PortOne 확인/웹훅 경로 미노출이었다. 이는 원격 fixture 적용 완료나 결제 성공의 근거가 아니다. 정확한 확인 시각·경로는 reports/server-paths.json에 있다.
