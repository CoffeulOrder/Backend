# 회원가입 이름 입력 정책 · 2026-11-27

태완과 합의한 이름 입력 상한은 **10자**다. `POST /api/v1/members`의 `name`에 적용한다.

- 한글·영문·숫자 및 공백을 포함한 이름을 허용한다. 공백도 전체 길이에 포함한다.
- 이름 전체가 비어 있거나 공백뿐이면 기존과 같이 거절한다.
- 10자 이하는 가입할 수 있고 11자 이상이면 HTTP 400 / `C001`을 반환한다.
- 길이 초과 시 `errors`에 `field: "name"`, `reason: "이름은 10자 이하로 입력해주세요."`를 전달한다.
- 이름 오류로 거절된 요청은 인증 토큰을 소비하지 않는다. 토큰의 유효기간 안에 이름을 고쳐 같은 토큰으로 다시 제출할 수 있다.

FE도 동일한 10자 제한과 안내 문구를 적용한다. API OpenAPI의 `MemberRegisterRequest.name.maxLength`는 10으로 제공된다. 기존 응답 필드와 회원가입 URL은 동일하다.

DB의 `member.name`은 `VARCHAR(30)`을 유지한다. 기존 10자 초과 회원과 긴 이름 QA 계정은 로그인·내 정보 조회에서 기존 이름을 반환하며, FE에서는 기존 데이터의 긴 이름 표시도 처리해야 한다. 스키마 변경이나 기존 이름 일괄 변경은 필요하지 않다.

검증은 실제 MySQL 통합 시험으로 한글·영문·숫자·공백 혼합 10자/11자 경계, 오류 후 토큰 재사용, 공백 이름 거절, 기존 20자 회원의 로그인·내 정보 조회를 확인한다.
